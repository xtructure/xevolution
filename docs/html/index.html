xevolution documentation

xevolution is a Python library for evolutionary computation. An application defines its candidates, evaluation, and variation operators; xevolution manages the population, selection, identities, history, and checkpoint continuation. This documentation covers version 0.1.1, including all three example applications.

Start here

If you are new to the package, read the overview for the central concepts and a walkthrough of one evolutionary run. Then choose an example from the examples guide. Each example has its own explanation of the genotype, fitness, operators, configuration, commands, and results.

Example What it demonstrates Guide
Arithmetic expression search Evolve a bit string, decode its expression, and score its distance from a target Arithmetic expressions
Shared-resource choices Evaluate the whole population when each candidate's score depends on other candidates Shared resources
Digits neural architecture search Evolve hidden layers and activation, train a fresh MLP, and use validation accuracy as fitness Digits MLP

The arithmetic and shared-resource examples use only the Python standard library. The Digits example uses the optional neural dependency group and runs on CPU. Every Python dependency belongs in a project-local virtual environment managed by uv.

Understand the port and its verification

The generic framework was ported from the Java Xnet xevolution sub-project. The new design uses Python composition, typed records, explicit JSON state, and application-defined extension contracts. NEAT, the graphical interface, the operator workbench, and compatibility with old Java runs are outside the agreed scope.

The Markdown edition starts at docs/markdown/index.md; the HTML edition starts at docs/html/index.html. The HTML edition includes local navigation, section links, highlighted code, and a search index. All reading assets are bundled, so opening it does not require a web server or an internet connection. External source references remain ordinary links to their original websites.

Both editions share the same Markdown content. Edit the Markdown and rebuild the HTML using the documentation build instructions.

The bundle retains the project's license text, accompanying GPL text, and source notice.
